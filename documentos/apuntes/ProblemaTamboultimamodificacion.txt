Problema Tambo Pastoreo con 
suplementación
Formular una dieta para vacas lecheras en 
pastoreo con las siguientes 
características:
• Peso vivo: 580 kg
• Producción de leche: 36 lt/d, 3.5% GB
• Días en leche: 65
Calcular,
• Consumo de materia seca
• La variación de peso vivo si la DMS de la 
dieta es igual a 70%
Supuestos
• CMS = 0.025 x PV + 0.22 x PL
• AV = 25%
• kl = 0.62
Estimación del CMS y energía
CMS = 0.025 x 580 + 0.22 x 36
CMS = 22.42 kg MS/d
EM/kg MS = 4.4 Mcal EB x 0.7 (DMS) x 0.82 = 
2.52 Mcal EM/kg MS
CE = 22.42 kg MS/d x 2.52 Mcal EM/kg MS = 
56.5 Mcal EM/d
Calculo de requerimientos
Peso = 580 kg
ENm = 0.085 x 580 0.75 x 1.25 = 12.55 Mcal EN/d
EMm = 12.55 / 0.62 = 20.24 Mcal EM/d
ENp (por tabla) = 0.69 Mcal EN/lt x 36 lt/d = 24.84 
Mcal EN/d
EMp = 24.84 / 0.62 = 40.06 Mcal EM/d
EMtotal = 20.24 + 40.06 = 60.3 Mcal EM/d
Balance energético y variación de 
peso corporal
Balance energético = CE – Req. Totales
BE = 56.5 Mcal EM/d – 60.3 Mcal EM/d
BE = - 3.8 Mcal EM/d
BE = -3.8 Mcal EM/d x 0.62 = - 2.36 Mcal EN/d
Pérdida de peso = - 2.36 / - 4.92 (tabla) =
- 0.48 kg/d
Cálculo de requerimientos
Requerimientos proteicos x tabla
Mantenimiento = 406 g/d (Tabla)
Producción = 84 g/lt x 36 lt = 
3024 g/d
Total = 406 + 3024 = 3430 g/d
PB dieta (%) = 3.43/22.42 = 15,3%
