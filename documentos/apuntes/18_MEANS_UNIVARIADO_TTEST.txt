Proc Means
Este procedimiento permite calcular estadísticos 
descriptivos para todos los valores de las variables 
numéricas o para grupos de observaciones:
Calcula estadísticos descriptivos basado en los 
momentos:
Media
Varianza
Coeficiente de kurtosis
Coeficiente de asimetría.
Estima cuantiles, que incluyen a la mediana.
Calcula intervalos de confianza para la media
Identifica valores extremos
Realiza el testt
PROC MEANS<opción(s)> <estadístico(s)>;  
BY <DESCENDING>variable-1 <... <DESCENDING> 
variable-n><NOTSORTED>;  
CLASSvariable(s) </ opción(s)>;  
FREQvariable;  
IDvariable(s);  
OUTPUT <OUT=DATA SAS><especificación(s) estadísticos> 
… </ opción(s)> ;  
VARvariable(s) < / WEIGHT=variable ponderación>;  
WEIGHTvariable;  
Proc Means SintaxisProc Means: estadísticos   
 
Estadísticos descriptivos 
CLM: intervalo de confianza para la media RANGE:  rango 
CSS: suma de cuadrados corregida SKEWNESS|SKEW: coeficiente de asimetría 
CV. coeficiente de variación STDDEV|STD: desvío estándar 
KURTOSIS|KURT: coeficiente de kurtosis STDERR: error estándar 
LCLM: límite inf. del intervalo de confianza UCLM: límite sup. del intervalo de confianza 
MAX: máximo SUMWGT: suma de las ponderaciones 
MEAN: media SUM: suma 
MIN: mínimo USS: suma de cuadrados sin corregir 
N: número de observaciones VAR: varianza 
NMISS: número de valores “missing”  
Cuantiles 
MEDIAN|P50: mediana Q3|P75: 3er. cuartil = 75avo. percentil 
P1: 1er. percentil  P90: 90avo. percentil 
P5. 5to. percentil P95: 95avo. percentil 
P10: 10mo. percentil P99: 99avo. percentil 
Q1|P25: 1er. cuartil= 25avo.percentil QRANGE: rango intercuartil 
Test de hipótesis  
PROBT: valor-p del estadístico t de Student T: estadístico t de Student

El procedimiento TTEST realiza el testtpara una y dos
muestras y para observaciones apareadas. 
También calcula:
El estadístico Fes calculado para probar la igualdad de dos
varianzas.
El test taproximadocuando las varianzas no son homogéneas
(problema de Behrens-Fisher).
Calcula los grados de libertad y el nivel de probabilidad
utilizando la aproximación de Satterthwaite's(1946) o de
Cochran y Cox (1950) para el test taproximado
BYvariables;
CLASS variables ; debe acompañar a PROC TTEST para el caso de dos 
muestras  independientes con solo dos niveles.
FREQ variable;
PAIRED Listado de las variables a aparear;Identifica las variables que 
intervendrán en comparaciones apareadas. En la siguiente tabla se 
muestran ejemplos del uso de asteriscos y dos puntos:
Estas sentencias PAIRED ... Indican estas comparaciones
PAIRED A*B; A-B
PAIRED A*B C*D; A-B y C-D
PAIRED (A B)*(C D); A-C, A-D, B-C, y B-D
PAIRED (A B)*(C B); A-C, A-B, y B-C
PAIRED (A1-A2)*(B1-B2); A1-B1, A1-B2, A2-B1, y A2-B2 
PAIRED (A1-A2):(B1-B2); A1-B1 y  A2-B2
VAR variables;
WEIGHT variable ;.

Proc Univariate
•calcula estadísticos descriptivos basados en 
momentos.
•calcula la media, modo, mediana, rango y cuantiles.
•calcula limites de intervalos de confianza.
•tabula observaciones extremas.
•genera tablas de frecuencia. 
•gráfica la distribución de los datos.
•realiza test de bondad de ajuste para distribuciones  
paramétricas y no paramétricas.
Este procedimiento provee estadísticos descriptivos, 
gráficos de alta resolución e información sobre la 
distribución de variables numéricas. Por ejemplo:
Continuación...
•crea histogramas y opcionalmente superpone las 
curvas de densidad para distribuciones continuas (beta, 
exponencial, gamma, lognormal, y Weibull).  
•crea gráficos Q-Q y probabilísticos para varias 
distribuciones teóricas y opcionalmente superponen 
líneas de referencias que corresponden a los parámetros 
especificados o estimados de posición y de escala para la 
distribución teórica. 
•crea histogramas, gráficos Q-Q y probabilísticos 
comparativos de una y dos vías.
•crea DATAS SAS para distintos estadísticos.

PROC UNIVARIATE
