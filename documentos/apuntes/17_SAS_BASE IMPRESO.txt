¿Que es el programa SAS? 
• El programa SAS es una colección de módulos que
incluyen “procedimientos ” y una poderosa herramienta de 
manejo de datos, que facilita el análisis estadístico de la 
información disponible.
• En general, SAS no se emplea de una manera interactiva
con menus o cuadros de diálogo, sino a través de 
“programas SAS ” escritos por el usuario, los cuales están
organizados en base a “sentencias y procedimientos ”
específicos, que son los elementos del lenguaje de 
programación SAS.
• Por lo tanto, el éxito en el uso de SAS, depende del 
aprendizaje de las reglas necesarias para escribir
programas SAS.

2003 - ANB
Ventanas de SAS
• PROGRAM EDITOR – ENHANCED EDITOR : en esta 
ventana se escribe el código SAS o programa SAS.
• LOG : en esta ventana se encuentra el archivo LOG que 
se genera cuando se ejecuta el programa SAS escrito en 
el Program Editor, el mismo contiene el código del 
programa con comentarios, avisos de errores (en rojo) y 
advertencias (en verde).
• OUTPUT : en esta ventana se muestran los resultados de 
la ejecución del programa.
• RESULTS : esta ventana permite manejar los archivos 
OUTPUT o de salida.
• EXPLORER : esta carpeta es usada para ver y manejar 
archivos (similar al programa Windows Explorer).
• KEY :  (F9) que permite crear atajos con las teclas de 
función o combinación de otras teclas.

Reglas del lenguaje SAS 
• Las órdenes SAS  terminan con un punto y coma ( ;). 
• Los nombres de las variables o de los archivos SAS pueden 
contener hasta 32 caracteres. 
• El primer carácter del nombre debe ser un letra o un guión 
bajo ( _). Los caracteres posteriores pueden ser letras, 
números o guiones. (No usar %, $, !, *, &, #, @)
• Las ordenes SAS pueden escribirse tanto en mayúsculas 
como en minúsculas (por ej: Body, body, boDY o BoDy).
• Los programas SAS son de formato libre:
• una línea puede contener más de una orden SAS,
• una orden SAS puede comenzar en una línea y continuar 
en la línea siguiente. 
• Las palabras en una orden SAS están separadas por blancos 
o por caracteres especiales (por ejemplo: $, @, =, +, *).

Archivos de datos SAS 
Temporarios y Permanentes
Los archivos de datos SAS pueden ser temporales a la ejecución del 
programa SAS o almacenarse en un carpeta en forma permanente 
para su posterior uso. 
• Archivos Temporarios : se almacenan automáticamente en la 
biblioteca (carpeta) de datos WORK, creada por SAS. 
• Archivos Permanentes : se almacenan en la biblioteca
SASUSER. El nombre del archivo SAS se compone, en este caso, 
del nombre de la biblioteca donde se almacenará, seguido de un 
punto y del nombre del archivo SAS, por ej: 
SASUSER.Magnolia .

Sentencias de uso general
Algunas sentencias son de uso general y no es necesario que
se encuentren en un paso DATA o PROC. Pueden encontrarse
en cualquier lugar del programa y tienen efecto hasta que
aparezca otra del mismo tipo.
TITLE[n] : 'título n-ésimo' (n <= 10); especifica títulos en la salida
de resultados.
FOOTNOTE[n] 'nota a pie de página n-ésima' (n <= 10); 
especifica notas a pie de página en la salida de resultados.
MISSING carácter ... ; especificación del carácter que representa
a los valores no observados , correspondientes a variables 
numéricas, donde carácter puede ser un valor alfabético o _
OPTIONS opción ... ; especificación de opciones SAS , en general 
dependientes del sistema operativo.
%INCLUDE ref ... ; inclusión de parte de un programa
procedente de otro archivo *.sas.

Sentencia condicional: IF-THEN-ELSE
• La sentencia IF-THEN-ELSE se utiliza para crear un archivo de 
datos, subconjunto de otro dado, con aquellas observaciones que
cumplen una determinada condición.
• Cuando no aparece la cláusula THEN, debe especificarse un 
punto y coma (;) después de la expresión.
• Si no aparece THEN no se puede especificar la sentencia ELSE.
• Si la expresión toma el valor verdadero se ejecutará la accion1 y 
si la expresión es falsa se ejecutará la accion2.
• La acción1 y acción2 son sentencias ejecutables, o bloques de 
sentencias comenzando por la sentencia DO.
Sintaxis:
IF condición [ THEN acción1 ; 
[ ELSE acción2; ] ]

PROC PRINT
Se utiliza cuando se necesita listar los valores de todas o 
algunas de las variables de un archivo de datos SAS. Se 
pueden crear variedad de informes a medida, clasificando los
datos en grupos y calculando totales y subtotales.
Sintaxis:
PROC PRINT <opciones>; 
BY <DESCENDING > variable-1 <...< DESCENDING > 
variable-n> < NOTSORTED >;
ID variable(s) ;
PAGEBY variable;
SUMBY variable ; 
SUM variable(s) ;
VAR variable(s) ;

PROC SORT
El PROC SORT ordena observaciones en un conjunto de 
datos para una o más variables, almacenando los resultados 
ordenados en conjuntos de datos SAS, que pueden 
reemplazar o no al existente. Su sintaxis es la siguiente: 
Sintaxis:
PROC SORT <opciones>; 
BY (DESCENDING ) variables ;
